The code in this repository is open under the Apache License 2.0 (see `LICENSE`).
You can use it, change it, and share it. The licence does not include the names
or the logo: section 6 of Apache-2.0 already says it grants no permission to use
the licensor's trade names or trademarks. This file explains, in plain words, how
PlayfulProcess asks you to handle them.

## What this covers

- The name **recursive.eco**.
- The name **Recursive** when it names these projects (Recursive Tarot,
  Recursive I Ching, and so on).
- The recursive.eco spiral logo.

PlayfulProcess uses these names and this logo as trademarks. This file does not
claim that any of them is registered.

## Forks are welcome

Copy it, change it, run your own. When you do:

- give your fork its own name and its own logo;
- don't present it as recursive.eco, or as an official recursive.eco project;
- don't suggest that PlayfulProcess made, runs or endorses it, unless you have
  agreed that together.

Keeping the copyright notices, `LICENSE` and `NOTICE` files, as Apache-2.0 asks,
is expected and is not a trademark problem.

## Saying what your work is for is fine

Plain, factual references are welcome. For example:

- "works with recursive.eco"
- "a grammar for recursive.eco"
- "forked from recursive-tarot by PlayfulProcess"

Write the name as plain text, and not more prominently than your own name.

## The logo

You may use the spiral logo as a link to recursive.eco, for example on an
"open in recursive.eco" button. Please don't use it, or something easily mistaken
for it, as the mark of your fork, product or channel.

## Content has its own licence

Grammars, text, images and audio are not covered by Apache-2.0. Each keeps its own
licence (CC-BY-SA-4.0 by default for grammar content; public-domain material stays
public domain). The README says which folders hold what.
